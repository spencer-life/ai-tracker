AI Tracker CLI

A high-performance, embedded Go telemetry engine designed to aggregate, parse, and visualize API costs and token utilization across autonomous AI agents (Claude Code, Antigravity, and Codex).

Built with Go, Cobra, and Bubbletea, AI Tracker operates passively. It intercepts agent transcripts, parses them locally using extreme performance optimizations, and provides an embedded real-time web dashboard wrapped in a beautiful Catppuccin Frappe aesthetic.

Enterprise Architecture

The 2.0 rewrite completely overhauled the ingestion pipeline to support massive log scales and concurrent readers/writers without locking or double-counting.

Byte-Offset Cursors

Instead of reading logs linearly and hashing every payload, the system now tracks exact file byte-offsets (file_cursors table). Sync times are O(1), instantly seeking to the end of the file.

SQLite WAL Concurrency

SQLite operates with Write-Ahead Logging (journal_mode=WAL) and a 5000ms busy timeout. This allows the backend to stream gigabytes of logs while the Web UI queries data concurrently without database is locked errors.

Structural Redaction

Logs often contain sensitive keys. Before ingestion, logs are unmarshaled, and string payloads are recursively scrubbed of AWS keys, JWTs, and API tokens. The raw text is discarded, preserving your privacy.

Embedded WebSockets

No separate node servers required. The Go binary embeds all Tailwind, GSAP, and HTML assets directly using go:embed. Telemetry flows instantly to the dashboard via a native Gorilla WebSocket broadcaster.

CLI Commands

The ait binary exposes several subcommands for managing ingestion, querying data, and launching interfaces.

ait sync

Manually parses all agent directories (~/.claude, ~/.gemini/antigravity-cli, ~/.codex) and syncs token usage into the local SQLite database.

-w, --watch Runs sync continuously in an infinite loop, streaming new logs to the database in real-time.
ait dashboard

Spins up the embedded Catppuccin Web Dashboard and WebSocket server. Serves static assets directly from memory.

--open Automatically opens the dashboard in your local web browser.
-p, --port Port to serve the dashboard on (default: 8080).
ait export

Extracts raw token usage and pricing telemetry for external agents or analysis tools like jq.

--json Output data in raw JSON format.
--out <file.zip> Automatically compress the JSON export into a ZIP archive for easy transferring.
--from / --to Filter telemetry data by date range (e.g. --from 2026-07-01).
ait clean

Safely wipes the local SQLite database (~/.config/ai-tracker/data.db) and resets all byte-offset cursors.

Configuration

By default, AI Tracker maps model names to their respective API costs (e.g., claude-3.5-sonnet at $3.00/M in, $15.00/M out). As AI vendors update pricing, you can override these defaults without recompiling the binary.

Custom Pricing File

Create a file at ~/.config/ai-tracker/pricing.json to override the cost logic dynamically:

{
  "claude-4.8-opus": {
    "input": 15.0,
    "output": 75.0
  },
  "fable-5": {
    "input": 2.0,
    "output": 8.0
  }
}

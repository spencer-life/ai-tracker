Local, source-backed usage analytics

AI Tracker

ai-tracker combines a Go CLI, terminal UI, and loopback-only browser dashboard for Codex, Claude Code, and agy sessions.

Install a release binary

mise use -g github:spencer-life/ai-tracker@v1.1.0
ai-tracker version
ai-tracker sync --rebuild

Release archives support Linux/WSL and macOS on x86-64 and ARM64. Windows users run the Linux release inside WSL. The one-time rebuild is required when upgrading from v1.0.0 and creates a timestamped database backup first.

To follow and install the newest stable release, run mise use -g github:spencer-life/ai-tracker@latest, then use mise upgrade github:spencer-life/ai-tracker for later updates. To remove it, run mise use -g --remove github:spencer-life/ai-tracker followed by mise uninstall github:spencer-life/ai-tracker. Manual downloads and checksums.txt are available from GitHub Releases; verify before extraction with sha256sum -c checksums.txt --ignore-missing on Linux or shasum -a 256 <archive> on macOS.

The archive also bundles the Codex skill under skills/ai-tracker. Copy that directory to $CODEX_HOME/skills/ai-tracker and restart Codex for a manual skill install.

Agy transcript estimates are opt-in. Run ai-tracker sync --include-estimates to import them and add --include-estimates to a report to display them. They remain labelled estimated.

Usage carries a reported, derived, estimated, or legacy quality label. Normal totals exclude estimates. Costs separately price uncached input, cache reads, cache writes, and output from an embedded vendor/ccusage-derived snapshot. Current Codex/OpenAI, Claude Opus 5, Fable 5, Sonnet 5, Gemini 3.6 Flash, and Gemini 3.1 Pro models are covered, including verified long-context tiers. Claude 5-minute and 1-hour cache writes are distinct when the source reports the breakdown; aggregate-only older rows use the 5-minute rate. Aggregate views exclude unknown-price events and show pricing coverage. These are standard API-equivalent estimates, not subscription, priority/fast-tier, storage, or tool billing. Rebuild after pricing/parser updates to reprice historical events.

Command reference

# Import or rebuild
ai-tracker version
ai-tracker sync
ai-tracker sync --watch
ai-tracker sync --rebuild

# Totals, calendar buckets, and sessions
ai-tracker usage --range 30d
ai-tracker daily --range 7d --tz America/Phoenix --json
ai-tracker weekly --range mtd --json
ai-tracker monthly --range custom --from 2026-01-01 --to 2026-07-01 --json
ai-tracker sessions --range 30d --agent codex

# Diagnostics and customization metadata
ai-tracker doctor
ai-tracker inventory
ai-tracker completion zsh

# Machine-readable output and exports
ai-tracker usage --range 30d --json
ai-tracker export --range 7d --csv --out usage.zip

# Interfaces
ai-tracker tui
ai-tracker dashboard --open

Report and export filters include --range today|7d|30d|mtd|custom, --from, --to, --tz, --agent, --provider, --model, --quality, --include-estimates, and --limit. Date ranges are half-open: the start is included and the end is excluded. Weekly buckets begin Monday. Human-readable report output is a range summary; the JSON form of daily, weekly, and monthly includes the selected bucketed series.

ai-tracker sync --rebuild creates a timestamped backup, clears all telemetry and checkpoints, and reimports canonical sources. Legacy rows survive in the backup rather than the rebuilt database. ai-tracker clean --yes also backs up before clearing, but does not reimport. Sync health reports usage events committed, session records committed, sources skipped, and actual source errors separately from informational diagnostics.

TUI and browser dashboard

ai-tracker tui shows 30-day Overview, Trends, Sessions, Agents/Models, Inventory, and Data Health views. Use number keys or arrows to change tabs, r to refresh, and q to quit.

ai-tracker dashboard performs an initial sync unless --no-sync is set, then serves the embedded dashboard on 127.0.0.1:8080. Only loopback hosts are accepted because the server has no remote authentication. The local API is under /api/v2; browser-triggered committed sync updates use server-sent events at /api/v2/events.

The dashboard includes range/timezone/model/provider/agent/quality filters, daily token charts with a table fallback, session pagination, breakdowns, inventory, and sync health.

Storage and privacy

By default, data is stored in ~/.config/ai-tracker/data.db. On Linux/WSL and macOS, directories use mode 0700; databases, backups, and exported files use 0600. Set AIT_DATA_DIR to move the data directory.

On first opening a v1 database, AI Tracker creates a backup under backups/ before adding the v2 schema. V2 reports query only the new source-backed tables.

The database stores accounting and session metadata, not prompt bodies, transcript text, hook commands, environment values, or full source paths. Source and project identifiers are hashed where appropriate. Inventory scans supported global configuration plus the current repository ancestry, returns basenames and stable hashes, and never executes discovered skills, hooks, agents, or plugins.
